# El sistema solar

Web en català per descobrir alguns dels mons més interessants del sistema solar. Inclou informació general, pàgines
dedicades a Mart i Saturn, una galeria d'imatges de la NASA i un formulari d'opinió.

Obre `index.html` en un navegador per començar. Les imatges de la galeria i la capçalera estan desades a `imatges/`;
les fitxes originals i els crèdits es poden consultar des de la galeria.
